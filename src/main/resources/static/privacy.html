นโยบายความเป็นส่วนตัว

ร่างตั้งต้น: เอกสารนี้เป็นแม่แบบ ผู้ให้บริการต้องแก้ข้อความในวงเล็บเหลี่ยม [ ] ให้ตรงกับความเป็นจริง และควรให้ผู้เชี่ยวชาญด้านกฎหมายตรวจก่อนเปิดใช้งานจริง ลบกล่องนี้ออกเมื่อแก้เสร็จ

สมุดภาษี ให้บริการโดย นักศึกษามหาลัยแม่ฟ้าหลวง ADT SE 68 ("เรา") เอกสารนี้อธิบายว่าเราเก็บ ใช้ และเปิดเผยข้อมูลส่วนบุคคลของคุณอย่างไร ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

ข้อมูลที่เราเก็บ

  • อีเมลและรหัสผู้ใช้ จากบัญชี Google ที่คุณใช้เข้าสู่ระบบ เราไม่ได้รับรหัสผ่าน Google ของคุณ
  • ข้อมูลที่คุณกรอกเอง ได้แก่ รายได้รายเดือนแยกตามประเภท ภาษีที่ถูกหัก สถานะสมรส จำนวนบุตรและผู้อยู่ในอุปการะ ค่าประกันและเงินออม และชื่อที่ให้เรียก
  • การตั้งค่าแจ้งเตือนทางอีเมล และบันทึกว่าเราส่งอีเมลฉบับใดให้คุณเมื่อใด

เราใช้ข้อมูลเพื่ออะไร

  • แสดงและคำนวณภาษีให้คุณในแอป
  • ส่งอีเมลแจ้งเตือนเรื่องการบันทึกรายได้และกำหนดเวลาภาษี เฉพาะเมื่อคุณติ๊กยินยอมในหน้าโปรไฟล์

เราไม่ขายข้อมูลของคุณ และไม่ใช้ข้อมูลรายได้เพื่อการโฆษณา

ฐานทางกฎหมาย

การให้บริการหลักอาศัยสัญญาที่คุณสมัครใช้งาน ส่วนการส่งอีเมลแจ้งเตือนอาศัยความยินยอมของคุณ ซึ่งถอนได้ทุกเมื่อโดยปิดการแจ้งเตือนในหน้าโปรไฟล์ หรือกดลิงก์ยกเลิกรับในอีเมล

ผู้ประมวลผลข้อมูลที่เราใช้

  • ผู้ให้บริการโฮสต์เซิร์ฟเวอร์และฐานข้อมูล: Google Cloud Platform (Cloud Run และ Cloud SQL (Asia-se1 singapore))
  • Google (เข้าสู่ระบบด้วยบัญชี Google)
  • ผู้ให้บริการอีเมลที่ใช้ส่งการแจ้งเตือน (SMTP เช่น Gmail): Google Gmail (SMTP)

ผู้ให้บริการบางรายอาจประมวลผลข้อมูลนอกประเทศไทย เราเลือกผู้ให้บริการที่มีมาตรการรักษาความปลอดภัยของข้อมูลตามมาตรฐานสากล

ระยะเวลาเก็บรักษา

เราเก็บข้อมูลของคุณตราบเท่าที่บัญชียังใช้งานอยู่ เมื่อคุณลบบัญชี ข้อมูลรายได้ โปรไฟล์ การตั้งค่าและบันทึกการส่งอีเมลจะถูกลบออกจากระบบของเรา สำเนาในระบบสำรองอาจคงอยู่ได้ไม่เกิน [จำนวน] วัน

สิทธิของคุณ

  • ขอเข้าถึงและรับสำเนา: ใช้ปุ่ม "ดาวน์โหลดข้อมูลของฉัน" ในหน้าโปรไฟล์
  • แก้ไขข้อมูล: แก้ได้เองในแอปทุกเมื่อ
  • ลบข้อมูล: ใช้ปุ่ม "ลบบัญชีและข้อมูลทั้งหมด" ในหน้าโปรไฟล์
  • ถอนความยินยอมรับอีเมล: ปิดการแจ้งเตือนในหน้าโปรไฟล์ หรือกดลิงก์ยกเลิกรับในอีเมล
  • ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล หากเห็นว่าเราไม่ปฏิบัติตามกฎหมาย
